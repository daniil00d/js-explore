# Лаба 01-2. Собери сложение по спецификации

**Сложность:** основная работа раздела. **Что тренируем:** чтение алгоритмов ECMA-262.

## Задача

Реализовать оператор `+` вручную — три функции в [`addition.mjs`](./addition.mjs):

| Функция | Абстрактная операция ECMA-262 |
| --- | --- |
| `toPrimitive(value, hint)` | [ToPrimitive, 7.1.1](https://tc39.es/ecma262/#sec-toprimitive) |
| `toNumeric(value)` | [ToNumeric, 7.1.4](https://tc39.es/ecma262/#sec-tonumeric) |
| `add(left, right)` | [ApplyStringOrNumericBinaryOperator, 13.15.3](https://tc39.es/ecma262/#sec-applystringornumericbinaryoperator) |

Пошаговые требования расписаны в комментариях заготовки — это пересказ
спецификации, читать сам стандарт не обязательно, но полезно.

## Как проверить

```bash
node 01-spec-and-semantics/labs/02-implement-addition/check.mjs
```

Пятьдесят одна проверка, и ни в одной нет заранее записанного ответа: эталон
считается на месте настоящим `+`, настоящим `Number` и настоящими приведениями.
Если твоя реализация разойдётся со движком хоть на одном случае, это будет видно.

Проверяется в том числе **порядок** побочных эффектов: объекты с логирующими
`valueOf`, `toString` и `Symbol.toPrimitive` должны вызываться в той же
последовательности, что и при настоящем сложении.

## На что обратить внимание

Случаи, на которых обычно и ломается наивная реализация:

- `1n + 1` — TypeError, а `1n + '1'` — строка `'11'`. Строковая ветка проверяется
  раньше числовой.
- `'метка: ' + Symbol()` — TypeError, хотя `String(Symbol())` работает нормально.
  ToString и `String()` — не одно и то же.
- `new Date(0) + 1` — строка, потому что у `Date` есть `Symbol.toPrimitive`,
  и на подсказке `'default'` он ведёт себя как `'string'`. Единственное место
  в языке, где `'default'` и `'number'` расходятся.
- `Object.create(null) + 1` — TypeError: у объекта нет ни `valueOf`, ни `toString`.
- Объект, чей `Symbol.toPrimitive` вернул объект, — тоже TypeError, и не в конце
  алгоритма, а сразу.

Пользоваться `left + right` внутри `add` не запрещено: числа где-то складывать
всё равно нужно. Интересное происходит до этого шага.
