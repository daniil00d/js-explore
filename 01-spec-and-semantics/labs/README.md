# Лабы раздела 01

Три задачи про правила языка: предсказать поведение, воспроизвести алгоритм
из спецификации, разобраться в порядке инициализации модулей.

| Лаба | Задача | Проверок |
| --- | --- | --- |
| [01-predict-the-output](./01-predict-the-output) | Предсказать результат четырнадцати фрагментов, не запуская их | 14 |
| [02-implement-addition](./02-implement-addition) | Реализовать оператор `+` по абстрактным операциям ECMA-262 | 51 |
| [03-module-order](./03-module-order) | Предсказать порядок инициализации в четырёх графах модулей | 4 |

Порядок такой и задуман: первая лаба показывает, где интуиция расходится
со спецификацией, вторая заставляет прочитать спецификацию как алгоритм,
третья переносит это на модули, где к правилам языка добавляется порядок
выполнения графа.

## Как это работает

```bash
node 01-spec-and-semantics/labs/01-predict-the-output/check.mjs
node 01-spec-and-semantics/labs/01-predict-the-output/check.mjs --solution
node tools/labs.mjs
```

Ни в одной проверке нет заранее записанных ответов: фрагменты действительно
выполняются в чистом контексте через `node:vm`, сложение сверяется с настоящим
оператором `+`, графы модулей по-настоящему импортируются. В лабах на
предсказание правильный ответ до зачёта не показывается — только его форма
(«список из 4») и подсказка.

Ничего устанавливать не нужно: всем трём лабам достаточно Node.
