# Лаба 01-3. Порядок инициализации модулей

**Сложность:** средняя. **Что тренируем:** графы модулей, циклы, `await` на верхнем уровне.

## Задача

В папке [`graph/`](./graph) лежат четыре маленьких графа модулей. Каждый пишет
в общий журнал строки вроде `a:start` или `b видит helperA: function`. Нужно
предсказать **порядок** этих строк для каждого графа и вписать массивы
в [`answers.mjs`](./answers.mjs).

| Граф | Точка входа | Про что |
| --- | --- | --- |
| `tla` | [`graph/tla-main.mjs`](./graph/tla-main.mjs) | верхнеуровневый `await` в одной из зависимостей |
| `esm-cycle` | [`graph/cycle-a.mjs`](./graph/cycle-a.mjs) | два модуля ESM импортируют друг друга |
| `cjs-cycle` | [`graph/cycle-a.cjs`](./graph/cycle-a.cjs) | та же пара на CommonJS |
| `dynamic` | [`graph/dyn-main.mjs`](./graph/dyn-main.mjs) | `import()` посреди выполнения модуля |

Файлы графа читать нужно — там всего несколько строк в каждом. Запускать до того,
как ответишь, неинтересно.

## Как проверить

```bash
node 01-spec-and-semantics/labs/03-module-order/check.mjs
```

Проверка по-настоящему выполняет все четыре графа и сравнивает журнал с твоими
массивами. Пока не сойдётся, показывается только длина ожидаемого списка.

## Вопросы, на которые придётся ответить по ходу

1. Что выполняется раньше: модуль, который импортируют, или тот, кто импортирует?
   И одинаково ли это в ESM и в CommonJS?
2. Останавливает ли `await` на верхнем уровне выполнение остальных модулей графа?
3. Циклическая пара: что видит второй модуль, обращаясь к экспортам первого
   в момент, когда тот ещё не дошёл до своих объявлений? И почему для функции
   и для `const` ответ разный?
4. `import()` от модуля, который лежит рядом на диске и уже разобран, — это
   всё-таки асинхронно или нет?

## Критерий готовности

`4 из 4`. Строки в массивах сравниваются дословно, включая пробелы и двоеточия.
