# Примеры раздела 00

Ничего устанавливать не нужно: всё работает на голом Node без зависимостей.
Команды в примерах записаны от корня репозитория.

## Быстрый старт

```bash
node 00-setup/examples/check-env.mjs                              # что у меня за окружение
node 00-setup/examples/flag-tour.mjs                              # что V8 умеет о себе рассказать
node --allow-natives-syntax 00-setup/examples/optimization-status.mjs
node --allow-natives-syntax 00-setup/examples/natives-syntax.mjs
```

## Что здесь лежит

| Файл | Что делает |
| --- | --- |
| `check-env.mjs` | Отчёт об окружении: версии, флаги сборки V8, доступность `d8` и `%`-функций |
| `flag-tour.mjs` | Запускает `subject.mjs` под разными флагами и показывает выжимку вывода |
| `subject.mjs` | Подопытная программа для тура: горячая функция, смена формы объекта, аллокации |
| `optimization-status.mjs` | Разбор `%GetOptimizationStatus`: уровни компиляции и ловушки |
| `natives-syntax.mjs` | Форма объектов, виды элементов массива, представление чисел и строк |
| `natives.mjs` | Обёртки над `%`-функциями с проверкой, что флаг вообще передан |
| `flags-cheatsheet.md` | Шпаргалка по флагам, разложенная по разделам репозитория |
| `d8-setup.md` | Установка `d8`, отличия от Node и когда он действительно нужен |
| `static-toolchain.md` | Библиотеки для статического трека: парсеры, TypeScript API, кодмоды |

## Порядок чтения

1. `check-env.mjs` — зафиксировать, на чём именно ты ставишь опыты. Дальше это придётся
   указывать в каждой заметке: половина наблюдений про V8 верна только для конкретной сборки.
2. `flag-tour.mjs` — увидеть все основные флаги за один запуск, без разбора деталей.
3. `optimization-status.mjs` — первый содержательный инструмент: он же понадобится в
   разделах 08 и 11, когда дойдём до уровней компиляции и деоптимизации.
4. `natives-syntax.mjs` — то же самое для формы объектов; пригодится в разделе 10.
5. Доки читаются по мере надобности: шпаргалка — как справочник, `d8-setup.md` — когда
   упрёшься в ограничения сборки Node, `static-toolchain.md` — на входе в раздел 02.

## Замечания

- Примеры печатают адреса объектов и счётчики вызовов, которые меняются от запуска к
  запуску. Совпадения цифр с тем, что написано в доке, ждать не стоит — важны порядки и
  переходы между состояниями.
- `flag-tour.mjs` поднимает дочерние процессы и пишет логи во временный каталог, который
  сам же удаляет за собой.
- Всё проверялось на `node v22.14.0 / V8 12.4.254.21-node.22` и `d8` (V8 15.5.18).
