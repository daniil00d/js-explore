# Лабы раздела 00

Две задачи на инструменты: одна — читать то, что говорит движок, вторая —
заставить его сказать нужное.

| Лаба | Задача | Проверок |
| --- | --- | --- |
| [01-flag-detective](./01-flag-detective) | По логам V8 выяснить, что случилось с четырьмя функциями | 5 |
| [02-pick-the-flags](./02-pick-the-flags) | Подобрать флаги, которые меняют поведение движка нужным образом | 5 |

## Как это работает

В каждой лабе есть задание (`README.md`), заготовка для ответа или решения,
проверка (`check.mjs`) и разбор (`solution.mjs`).

```bash
node 00-setup/labs/01-flag-detective/check.mjs              # проверить своё
node 00-setup/labs/01-flag-detective/check.mjs --solution   # посмотреть зачёт
node tools/labs.mjs                                         # обзор всех лаб репозитория
```

Проверки не хранят правильных ответов: они запускают подопытные программы
с флагами и сверяют ответ с тем, что сказал движок. Поэтому лабы остаются
честными и на другой версии V8, где числа и формулировки могут отличаться.

Ничего устанавливать не нужно: обеим лабам достаточно Node.
