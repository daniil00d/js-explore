# Лаба 00-2. Подбери флаги

**Сложность:** средняя. **Что тренируем:** `node --v8-options` как рабочий справочник.

## Задача

Дана программа [`probe.mjs`](./probe.mjs) — три функции и цикл, мусорящий памятью.
Нужно подобрать флаги V8, которые заставят движок сделать пять разных вещей:

1. напечатать байткод **только** функции `hotLoop`;
2. отправить `hotLoop` в оптимизирующий компилятор, хотя её вызывают три раза;
3. не дать горячей `spin` выйти за пределы интерпретатора;
4. показать, когда работает сборщик мусора;
5. заставить сборки мусора происходить заметно чаще.

Флаги вписываются массивами в [`flags.mjs`](./flags.mjs). Программу менять нельзя —
в этом весь смысл: поведение движка настраивается снаружи.

## Как проверить

```bash
node 00-setup/labs/02-pick-the-flags/check.mjs
```

Проверка не сравнивает флаги со списком «правильных», а смотрит на результат:
запускает `probe.mjs` с твоими флагами и проверяет, изменилось ли поведение.
Любой рабочий вариант пройдёт, в том числе не тот, что в разборе.

## С чего начать

Главный инструмент здесь один:

```bash
node --v8-options                       # все флаги с описаниями, около 1500 строк
node --v8-options | grep -i bytecode    # так им и пользуются
node --v8-options | grep -i -A2 'max-opt'
```

Пара наблюдений, которые пригодятся:

- у булевых флагов есть отрицательная форма: `--lazy` и `--no-lazy`;
- флаги со значением пишутся через `=`: `--max-opt=2`;
- флаги V8 и флаги Node — разные наборы, но передаются одинаково.

Полезные разделы шпаргалки: [`../../examples/flags-cheatsheet.md`](../../examples/flags-cheatsheet.md).

## Критерий готовности

`5 из 5`. Отчёт по каждому пункту говорит, что именно не сошлось: например,
«напечатано функций: 214» — значит, печать байткода включена, но не ограничена.

## Если застрял

<details>
<summary>Пункт 1: почему одного флага мало</summary>

`--print-bytecode` печатает байткод всего, что компилируется, включая внутренности
Node — это десятки тысяч строк. Рядом с ним в `--v8-options` живёт второй флаг,
который принимает имя функции.
</details>

<details>
<summary>Пункт 2: подсказка по названию</summary>

Ищи среди флагов со словом `always`. Оптимизация обычно включается по порогу
вызовов, а этот флаг порог убирает.
</details>

<details>
<summary>Пункт 3: подсказка по названию</summary>

`node --v8-options | grep -A2 'max-opt'`. Уровни нумерованы: интерпретатор,
Sparkplug, Maglev, TurboFan.
</details>

<details>
<summary>Пункты 4 и 5: где искать</summary>

`node --v8-options | grep -i gc` и `node --v8-options | grep -i semi-space`.
Молодое поколение в V8 состоит из двух полупространств (semi-space), и его размер
задаётся флагом в мегабайтах.
</details>

## Разбор

[`solution.mjs`](./solution.mjs) — рабочий набор флагов с объяснением, что делает
каждый и когда он опасен. Отдельно там сказано про разницу между флагами, которые
только наблюдают, и флагами, которые меняют поведение движка: первые можно
оставлять в диагностике, вторые ломают любые замеры.

```bash
node 00-setup/labs/02-pick-the-flags/check.mjs --solution
```
